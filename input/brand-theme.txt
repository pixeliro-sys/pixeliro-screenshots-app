HOW TO UPDATE THIS FILE
==================================================

Method 1 — From Brand Palettes gallery:
  1. Open https://pixeliro.com/brand-palettes
  2. Click any palette → opens detail page
     https://pixeliro.com/brand-color-palette/<uuid>
  3. Click tab "Export"
  4. Choose format: Other → Plain Text
  5. Download → replace this file

Method 2 — From Brand Color Generator:
  1. Open https://pixeliro.com/brand-color-palette
  2. Describe your brand → click Generate
  3. Click "View Details" button
     → opens https://pixeliro.com/brand-color-palette/<slug>
  4. Click tab "Export" → Other → Plain Text
  5. Download → replace this file

Then regenerate screenshots:
  npm run gen:theme:brand          # all devices × locales
  npm run gen:theme:preview        # iphone × en-US (quick check)
